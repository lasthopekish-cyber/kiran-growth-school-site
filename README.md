## How the site is built

The site is static HTML generated by a small Python script. Do not hand-edit the generated HTML; edit the sources and rebuild.

| What | Where |
|---|---|
| Services, industries, cities, courses, home FAQ | `build/data.py` |
| Page templates and SEO (titles, schema, sitemap, robots, llms.txt, RSS) | `build/build.py` |
| Blog posts (Markdown) | `content/blog/*.md` |
| Styles, script, images | `assets/` |

```bash
pip install markdown
python3 build/build.py      # regenerates every page, sitemap.xml, robots.txt, llms.txt, blog/feed.xml
```

Posts with a future `date:` are skipped until that date (IST), so you can schedule posts by date.
